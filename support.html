怎么玩？

给机器写规则：读到 0 怎么办，读到 1 怎么办，下一格交给哪个状态。按运行键看它工作，满意了再按提交键。第一关会一步一步带你做。

卡关了怎么办？

点右上角的齿轮，选"提示"。实在想不出来可以选"查看答案"，不过这一关就只能拿铜牌了。

为什么"运行"对了，"提交"却没通过？

提交会把 128 种纸带全部试一遍，每一种都要变对才算通过。没通过时，结果页会给出一条出错的纸带，可以点"看一遍"看看机器是怎么走的。

字太小了？

在"设置 → 字号"里选"大"或"特大"。深色、浅色也在设置里切换。

换手机后进度还在吗？

进度只保存在这台设备上，不会上传，所以换手机或删除游戏后需要从头开始。

Turing Machine Puzzle · Support

Found a problem, a mistake, or have an idea? Email us; we usually reply within a few days:

yanghao.anderson@gmail.com

Including your device and iOS version (for example iPhone 15, iOS 18) helps us find the cause faster.

How do I play?

Write rules for the machine: what to do when it reads a 0, what to do on a 1, and which state takes the next cell. Press Run to watch it work, then Submit when you're happy. The first level walks you through it.

I'm stuck

Tap the gear in the top-right corner and choose Hint. If you're really stuck, Show answer is there too, but that level can then only earn bronze.

Run looked right, but Submit failed

Submit tries all 128 tapes, and every one must come out right. When it fails, the result screen shows a tape that went wrong; tap Watch it to see what the machine did.

The text is too small

Choose Large or Largest in Settings → Text size. Light and dark themes are in Settings too.

Will my progress move to a new phone?

Progress is saved only on this device and never uploaded, so a new phone or a reinstall starts from the beginning.
